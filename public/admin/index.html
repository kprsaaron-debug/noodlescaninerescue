How editing works

  1. Click any text on the page and type to change it.
  2. Click a photo to swap it for a new one or update its description.
  3. Add or remove things — select a block (like a news card) and use Duplicate, Move or Delete.
  4. Save draft to keep working later, or Publish to put it live.
  5. Every version is kept in History, so any change can be undone.
